# Bowtie nanogap example

**Role:** example

**Status:** current; it holds no solver input yet
([`../../docs/plans/plan.md`](../../docs/plans/plan.md) § 4)

**Authority:** example inputs only; scientific and environment contracts remain
normative

This directory is reserved for the first application model. It contains no
solver input yet: geometry and physics will be introduced through the common
schema after the analytic Maxwell benchmark is validated in both engines.

Planned study axes include electrode length, gap resolution, exterior-domain
padding, PML thickness, water/air medium, wavelength, and effective tunneling
conductivity. Numerical axes and physical axes will remain separate studies.
